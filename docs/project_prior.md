## P0 — 프로젝트 핵심 기능 (Core Identity)

| 순위 | 항목 | 비고 |
|---|---|---|
| 1 | **YOLOv11 + SAM 2 시각 객체 탐지** (FR-01) | 프로젝트 정체성. 현재 0% 구현. Colab 파이프라인에 `VisualDetect` 단계 추가 필요 |

| 4 | **시각 객체 블러/모자이크 치환** (FR-07) | SAM 2 마스크 → ffmpeg overlay. STE 합성(FR-10)보다 먼저 |
